# IR3-11 — Employee portrait source

Created with the built-in image generation tool on 2026-10-19, based on the archivist T-pose concept from this project conversation.

- `IR3_11_Employee_01_EyesClosed.png`: employee portrait, eyes closed.
- `IR3_11_Employee_02_EyesOpen.png`: edit of the first image, eyes open, preserving the identity and composition.
- Blank state is a neutral paper texture authored in Unity; the employee dossier text stays separate from the photograph.
- Dossier/stamp font: [Noto Sans Regular](https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans), bundled in `Fonts/` with the upstream SIL Open Font License in `Fonts/OFL.txt`.

Closed-eyes prompt:

> Create an employee identification portrait texture for a psychological horror archive office game. Reference image is the exact identity and costume reference: preserve this woman's face, pale tired skin, brown hair tied back with loose strands, beige worn button-up shirt. Single front-facing head-and-shoulders passport photograph, centered, eyes CLOSED naturally, lips neutral, restrained unsettling stillness. Desaturated aged analog photograph, subtle paper grain, soft even light, off-white plain background. Straight frontal view, no pose changes, whole head and shoulders visible. Portrait aspect 3:4. This is the photograph itself filling the image, not a card or frame; no border, no words, no badges, no text, no logos, no gore. Facial structure must match the referenced concept.

Preserve exactly the same woman's identity, mouth, facial proportions, head position, hair, shoulders, cream office shirt, background paper stains, photograph grain, lighting, color grading, image framing, dimensions. No smile, no gore, no extra objects, no words. This must match the closed-eye version when switched as a texture on the same employee dossier.
